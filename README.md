# StudentOS

StudentOS is a command-line student management system developed in C.

## Current Features
- Student profile creation
- Display student profile
- Update profile details
- Semester validation

## Planned Features
- Assignment management
- Study tracker
- Expense management
- Academic reports

## Technologies Used
- C Programming
- Structures
- Functions
- Loops and conditional statements
- Standard input/output

## Project Status
Currently under development. New features will be added module by module.
